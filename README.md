# Praias pelo Mundo

Projeto desenvolvido com HTML5 e CSS3 com foco em estrutura semântica, responsividade e aplicação de layouts modernos utilizando Flexbox e Grid Layout.

O site apresenta uma vitrine de praias paradisíacas, além de demonstrar conceitos fundamentais de desenvolvimento front-end moderno.

## Objetivo do Projeto

O projeto foi criado com o objetivo de praticar:

- Estruturação semântica com HTML5
- Organização visual com CSS3
- Layouts modernos com Flexbox e Grid
- Responsividade para diferentes dispositivos
- Componentização visual
- Organização profissional de arquivos

---

### CSS Moderno

O projeto utiliza:

- Variáveis CSS (`:root`)
- Flexbox
- Grid Layout
- Responsividade com `@media`
- Gradientes
- Overlay em imagem
- Sombras e transições
- Efeitos hover
- Animações suaves

---

## Responsividade

O site foi desenvolvido para adaptação em:

- Desktop
- Tablets
- Smartphones

A responsividade foi construída utilizando:

```css
@media (max-width: 980px)
```

e

```css
@media (max-width: 640px)
```
